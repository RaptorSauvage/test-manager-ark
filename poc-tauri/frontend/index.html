        Discord bot subsystem

        Calls the real, unmodified startDiscordBot()/stopDiscordBot()/ getDiscordBotStatus() from lib/discordBot.ts, which `fork()`s the real src/bot/index.ts (bundled unmodified, zero Electron imports) as its own OS process - a different real subsystem, not just the main-process logic above. Known PoC-sandbox caveat (see README's "Sidecar packaging"): when the sidecar runs as the compiled SEA binary (the default), Node's single-executable packaging makes fork() relaunch the sidecar's own embedded entry point instead of the bot script - it won't actually reach Discord either way (no outbound network to discord.com in this sandbox, and a fake token regardless), but under SIDECAR_PATH dev mode it does reach a real connection attempt and exit cleanly, which is the more informative run to try first.
